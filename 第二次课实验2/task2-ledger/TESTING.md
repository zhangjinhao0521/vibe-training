## 核心代码理解

程序把每套穿搭保存成一个字典，把全部字典放进列表。新增或删除记录时，先修改这份内存列表，再把整个列表转成 JSON 写入本地文件；程序下次启动时再把 JSON 读回列表，所以退出后数据不会消失。先写临时文件再替换正式文件，是为了降低保存中断造成数据损坏的可能。
