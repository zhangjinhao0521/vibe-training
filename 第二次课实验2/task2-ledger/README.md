# 个人穿搭记账本

一个只使用 Python 标准库的命令行小工具，用来记录每日穿搭、回看与筛选记录、总结月度偏好，并为下个月推荐穿搭。

## 运行环境

- Windows 终端
- Python 3.12（3.10 及以上也可）
- 不需要安装第三方库

## 启动方法

在本文件夹打开终端，运行：

```powershell
python ledger.py
```

首次保存记录后，程序会在当前文件夹生成 `data.json`。再次启动时会自动读取其中的数据。

## 功能

1. 记录今日穿搭：日期、上装、下装、鞋履、颜色、风格、场合、满意度和备注。
2. 查看全部记录，或按月份、风格、颜色、场合筛选。
3. 按月统计记录次数、平均满意度、常穿单品、风格、颜色和场合。
4. 根据当月真实记录和满意度，为下个月推荐 1～3 套搭配。
5. 按编号删除记录，删除前必须二次确认。

## 使用说明

- 日期格式为 `YYYY-MM-DD`，记录时直接回车默认今天。
- 多种颜色可用中文或英文逗号分隔，例如 `白色，蓝色`。
- 满意度只能输入 1～5 的整数。
- 月份格式为 `YYYY-MM`，汇总时直接回车默认本月。
- 数据文件损坏时，程序会先生成 `data.invalid-时间.json` 备份，再从空记录开始，避免直接覆盖原数据。

## 文件结构和数据流向

项目由程序 `ledger.py`、本说明和运行后生成的 `data.json` 组成。程序启动时，`load_records()` 从 JSON 读取所有记录到内存列表；用户通过菜单新增、查看、汇总或删除。新增和删除会修改内存列表，再由 `save_records()` 先写入临时文件，完整落盘后替换正式数据文件；查看和汇总只读取列表，不改数据。程序每次重新启动都会再次读取 `data.json`，因此记录可以长期保存。

## 读取和保存的核心逻辑

- `DATA_FILE` 默认指向程序同目录的 `data.json`。
- `load_records()` 先判断文件是否存在；不存在就返回空列表。
- 文件存在时用 UTF-8 打开并通过 `json.load()` 转成 Python 数据。
- 数据不是列表、JSON 损坏或个别记录字段异常时，程序给出提示，并尽量保留原文件备份。
- `save_records()` 先创建数据目录，再将完整列表写到临时文件。
- `ensure_ascii=False` 让中文直接保存在 JSON 中，`indent=2` 让文件便于人工查看。
- `flush()` 和 `os.fsync()` 确保内容落盘，最后用 `replace()` 一次性替换正式文件，降低写到一半时文件损坏的风险。

## 验收结果

- M1：新增、日期默认值、错误日期与满意度重试、UTF-8 JSON 保存、重启读取均通过。
- M2：查看全部、月份/风格/颜色/场合筛选、空记录和无匹配提示均通过。
- M3：3 条测试记录的数量、平均满意度 4.0、偏好频次和下月推荐均通过；12 月到次年 1 月的计算通过。
- M4：满意度边界 1/5、超长备注、菜单与编号乱输入、取消/确认删除、空数据、损坏 JSON 备份均通过。
